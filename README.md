## 1. 程式用途與執行方式
本程式用於自動計算朋友聚餐的費用分攤。程式會自動清理原始的文字資料（如去除貨幣符號與空白），進行資料轉型，接著依序計算服務費（以原價計算）、扣除折價券，最後算出應付總額與每人平均費用，並自動判斷是否超過預先設定的預算。
- **執行方式**：請在 Google Colab 開啟 `dinner_split_[你的學號].ipynb`，依序點擊儲存格左側的「播放鍵」執行程式，即可看到輸出結果。

## 2. 三組測試結果摘要
* **測試一**（4人，折價券100）：應付總額 1220.00 元，每人 305.00 元，超過預算 (True)。
* **測試二**（5人，折價券100）：應付總額 1220.00 元，每人 244.00 元，未超過預算 (False)。
* **測試三**（4人，折價券220）：應付總額 1100.00 元，每人 275.00 元，未超過預算 (False)。

## 3. 問題回答

**問題一：為什麼 `"4"` 要先轉成數字，才能用於本題的分攤計算？**
> **回答**：因為在 Python 中，帶有引號的 `"4"` 是「字串（文字）」型別，字串無法用來進行除法 (`/`) 等數學運算。如果不轉成整數（`int`）或浮點數，程式在計算「應付總額 / 人數」時會發生型別錯誤（TypeError）。

**問題二：如果先扣折價券，再依剩餘餐費計算服務費，第一組的應付總額會變成多少？為什麼和題目規定的結果不同？**
> **回答**：如果先扣除折價券，計算過程會變成：(1,200 - 100) = 1,100，接著算服務費 1,100 * 0.1 = 110。最後總額是 1,100 + 110 = **1,210 元**。這和題目規定的 **1,220 元**不同，因為餐廳的規定是「服務費按原始餐費收取」，先扣折價券會導致服務費的計算基準變小，讓餐廳少收了 10 元的服務費。
